Report status

EndpointBodyEffect
POST /awaiting_user_input{title, message, session_id?, context?, origin?, agent?, tool_use_id?, turn_started_at?}Row becomes input_needed
POST /all_tasks_finished{title, message, session_id?, context?, origin?, agent?, turn_started_at?}Row becomes done
POST /task_failedsameRow becomes failed
POST /working{session_id, title?, message?, context?, origin?, agent?, only_if_waiting?, tool_use_id?}Row becomes working; returns {updated, notification?}. only_if_waiting only resumes a waiting row.

Rows are keyed by session_id (omitted IDs share one row). Title 1–200 characters, message 1–4000. agent is claude_code or codex. context: cwd, work_arc, current_ask, repo_name, repo_description (blank clears). origin holds terminal/tmux focus hints (see AGENTS.md).

Rows also carry service-assigned times (RFC 3339 UTC, each omitted when unknown): tracked_since (first report, kept until the row is cleared), updated_at (latest agent report, including finished tools that changed nothing), task_started_at (prompt that started the current task), task_finished_at (done/failed only), waiting_since (input_needed* only), dismissed_at (cleared by the next agent update), last_request_at (any request touching the row), user_action_at (Dismiss, Stop sound, or Focus here or in the app), and user_input_at (a prompt or answer in the terminal, from the hooks). Requests cannot set them, except that an alert's optional turn_started_at (from the agent's transcript) fills an unseen task start when it falls after the previous task ended. Hover a task's timing line for all of them.

Act on tasks

EndpointEffect
POST /acknowledge/{id}Dismiss: an alerting row goes quiet and stays listed. {stopped}
POST /dismiss/{id}Clear: remove the row. {stopped}; stale IDs are harmless
POST /focused/{id}Tray app reports a Focus; records user_action_at only. {recorded}
POST /stopClear every row, cancel any snooze, stop all audio
